Terminal serial

  • Conectar abre el puerto seleccionado con el baudrate configurado.
  • Si el puerto está en auto, Enki elige el puerto USB serial recomendado.
  • Enviar manda la línea escrita al ESP32 y agrega salto de línea automáticamente.
  • Puedes enviar texto plano o JSON Lines, por ejemplo {"cmd":"ping"}.
  • /help imprime esta ayuda dentro de la terminal sin enviar nada a la placa.
  • Limpiar borra la vista local de la terminal; no reinicia la placa.
  • Cmd+L o Ctrl+L limpia la terminal cuando el cursor está en la entrada.
  • Los botones Build, Flash y Clean están arriba; esta terminal solo muestra y envía serial.
